# Запуск ассистента на Windows-ПК: микрофон, наушники, управление компьютером

Тот же сервер, тот же мозг — но «колонкой» становится ваш компьютер:
микрофон ПК или USB-гарнитура как вход, наушники как выход, плюс новое
умение — **голосовое управление самим ПК** (сервер и клиент работают
на одной машине, поэтому ассистент управляет именно вашим компьютером).

## 1. Установка (один раз)

1. Установите **Python 3.10–3.12 x64** с python.org
   (галочка **Add Python to PATH** обязательна).
2. Скопируйте папку проекта в удобное место, например `C:\assistant`.
3. Двойной клик по `pc\install_pc.bat`. Скрипт:
   - создаёт виртуальное окружение `.venv`;
   - ставит PyTorch (CPU-сборка) и все зависимости сервера и клиента;
   - скачивает модели речи Vosk (~50 МБ) и Silero (~120 МБ).

Установка может занять 10–20 минут — почти всё время качаются модели.

## 2. Запуск

Двойной клик по `pc\start_pc.bat` — откроются два окна:

| Окно | Что делает | Закрывать? |
|---|---|---|
| «Сервер ассистента» | мозг, распознавание, синтез речи | ❌ только сворачивать |
| «Ассистент: микрофон» | стримит микрофон, играет ответ | ❌ сворачивать |

Появится строка `=== Пиби на связи. Скажите «Пиби», затем команду. ===`.
Скажите имя, дождитесь «Слушаю!», произнесите команду. Пауза между
фразами — полторы секунды тишины, дальше ассистент ответит.

Полезные флаги клиента:

```bat
python pc\assistant_pc.py --list-devices   :: номера микрофонов
python pc\assistant_pc.py --device 2       :: конкретный микрофон
python pc\assistant_pc.py --no-mic         :: чат с клавиатуры (без микрофона)
python pc\assistant_pc.py --text "который час"
python pc\assistant_pc.py --url ws://192.168.1.10:8000/ws   :: сервер на другом ПК
```

## 3. Голосовые команды управления ПК

| Фраза | Что произойдёт |
|---|---|
| «открой браузер» / «открой блокнот» / «открой калькулятор» | запуск приложения |
| «открой телеграм», «открой спотифай», «открой стим», «открой дискорд» | запуск установленных программ |
| «закрой хром», «закрой блокнот» | закрыть процесс приложения |
| «громкость на 50» | точная громкость системы (0–100) |
| «громче» / «тише» | шаг громкости в наушниках/динамике |
| «выключи звук» / «включи звук» | мьют системы |
| «поставь на паузу», «дальше» | медиа-клавиши → любой активный плеер |
| «сделай скриншот» | PNG в `Рабочий стол\Скриншоты ассистента` и откроется папка |
| «напиши привет, мир» | вставит текст (Ctrl+V) в активное окно |
| «сверни все окна» | Win+D, покажет рабочий стол |
| «заблокируй компьютер» | Win+L-блокировка |
| «выключи компьютер» / «перезагрузи компьютер» | через 60 секунд, с возможностью отмены |
| «отмени выключение» | отмена таймера выключения |
| «команды пк» | ассистент перечислит эти команды |

Список известных приложений — словарь `APPS` в
`server/assistant/brain/skills/pc.py`. Добавьте свою программу: имя,
команда запуска (`start имя_ярлыка`), синонимы — и она открывается голосом.

## 4. Микрофон и наушники

- Клиент берёт **устройство ввода по умолчанию**, а играет в **устройство
  вывода по умолчанию**. Выберите гарнитуру в Windows: Параметры → Система
  → Звук (вход и выход).
- Перебивание работает: скажите имя во время ответа — озвучка остановится.
- Эхоподавление: Chromium-версия делала его сама; на ПК микротон слышен
  реже, но если наушники сильно пропускают звук наружу, ассистент может
  «услышать» сам себя — уменьшите громкость или скажите имя (перебивание
  остановит фразу).

## 5. Автозапуск при включении ПК

1. `Win+R` → `shell:startup` → Enter.
2. Скопируйте туда ярлык `pc\start_pc.bat` (ПКМ → Создать ярлык →
   перетащить в папку автозагрузки).

Сервер и клиент будут стартовать вместе с Windows.

## 6. Безопасность

- Умение «компьютер» выполняется **там, где запущен сервер**. Если сервер
  на VPS, «выключи компьютер» выключит VPS — держите сервер на своём ПК.
- Выключение и перезагрузка всегда идут через 60-секундный таймер с отменой.
- Клиент без токена подключается только к localhost; для доступа из сети
  задайте `server.token` в `config.yaml` и параметр `--token` клиенту.
- `pyautogui` двигает курсор и жмёт клавиши — не трогайте мышь в момент
  команды «напиши …».

## 7. Типичные проблемы

| Симптом | Решение |
|---|---|
| «python не найден» в bat | Переустановите Python с галкой Add to PATH, запустите install заново |
| Клиент не подключается | Сервер ещё стартует (окно сервера живо? порт 8000 свободен?) — клиент переподключается сам |
| Тишина с микрофона | Проверьте вход по умолчанию; `--list-devices` → `--device N` |
| Ответ играет в динамики, а не в наушники | Наушники должны быть устройством вывода по умолчанию |
| «Для точной громкости поставьте pycaw» | `pip install pycaw comtypes` в venv (install_pc.bat ставит сам) |
| Антивирус ругается на pyautogui | Это норма для библиотек автоклика — добавьте папку проекта в исключения |
| Не узнаёт имя «Пиби» | Говорите чуть медленнее; в `config.yaml` добавьте варианты в `wake_words` |

## 8. Если Пиби лагает: секция performance

В конце `config.yaml` есть секция, которая подгоняет сервер под слабый ПК:

```yaml
performance:
  torch_threads: 2            # сколько ядер отдаём нейросетям (2-4 обычно достаточно)
  process_priority: "normal"  # приоритет процесса сервера
  tts_warmup: true            # прогрев голоса при старте
```

- **`torch_threads`** — нейросети (распознавание + синтез) перестают съедать
  все ядра: интерфейс Windows и другие программы не подтормаживают во время
  ответа Пиби. `0` — разрешить torch использовать все ядра.
- **`process_priority`** — `below_normal`: Пиби работает в фоне и уступает
  место играм и браузеру (хороший вариант для игрового ПК); `above_normal`:
  наоборот, максимальная отзывчивость ассистента.
- **`tts_warmup`** — при старте сервер сразу синтезирует тестовую фразу:
  первый настоящий ответ звучит без 2–3-секундной задержки. `false` — если
  не хотите лишних пары секунд при запуске.
