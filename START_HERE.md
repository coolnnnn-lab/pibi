# Пиби на вашем ПК + сервер на VPS — быстрый старт

Этот пакет — только «исполнительная часть» для Windows-ПК: микрофон
вашего ПК стримится на сервер Пиби на VPS, ответ приходит в наушники.
Вся нагрузка (распознавание речи, мозг, синтез голоса) — на сервере,
компьютер почти не нагружается.

## Что нужно до установки

1. Сервер Пиби развёрнут на VPS — пакет `pibi-server.zip`, инструкция
   внутри: `docs/DEPLOY.md`.
2. Python 3.10–3.12 x64 с python.org — при установке отметьте
   **Add Python to PATH**.
3. Два значения с сервера:
   - **IP сервера** (например `185.10.10.1`);
   - **токен** — строка `server.token` из `server/config.yaml` на VPS
     (задаётся при настройке сервера, шаг 4 в DEPLOY.md).

## Установка (один раз, 2–5 минут)

1. Распакуйте папку `pibi-pc` в удобное место, например `C:\pibi-pc`.
2. Двойной клик по `pc\install_client.bat` — ставит только клиентские
   зависимости (микрофон, звук, умение «компьютер»), без нейросетей —
   они на сервере.

## Запуск

1. Двойной клик по `pc\start_client.bat`.
2. Первый запуск спросит IP и токен и сохранит их в `pc\server.cfg`
   (удалите этот файл, если нужно настроить заново).
3. Скажите **«Пиби»**, дождитесь «Слушаю!», произнесите команду.
   Пауза между фразами — полторы секунды тишины.

## Проверка без микрофона

В окне `cmd` из папки `pibi-pc`:

```bat
.venv\Scripts\python pc\assistant_pc.py --url ws://IP_СЕРВЕРА:8000/ws --token ТОКЕН --text "который час"
```

Полезные флаги:

| Флаг | Что делает |
|---|---|
| `--list-devices` | номера микрофонов |
| `--device N` | выбрать конкретный микрофон |
| `--no-mic` | чат с клавиатуры, без микрофона |
| `--text "фраза"` | отправить одну команду и выйти |

## Голосовое управление этим ПК

Так как клиент стоит на самом ПК, команды «компьютер» исполняются
локально: «открой браузер», «закрой хром», «сделай скриншот»,
«громкость на 50», «выключи звук», «сверни все окна», «заблокируй
компьютер», «напиши привет». Всё остальное (погода, таймеры, музыка,
память) считает сервер на VPS.

## Если не подключается

- `Connection refused` — сервер не запущен или порт 8000 закрыт:
  на VPS выполните `sudo ufw allow 8000/tcp` (если включён ufw).
- `403 / token` — токен в `pc\server.cfg` не совпадает с `server.token`
  в config.yaml на сервере. Исправьте файл или удалите его и введите
  заново.
- Микрофон не тот — `--list-devices`, затем `--device N`.
